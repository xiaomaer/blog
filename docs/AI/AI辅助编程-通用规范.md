
# rule（编码规范、安全红线、代码风格）
* ai coding的所有内容必须是英文
* 优先使用@heyrvia/**组件，如果仓库中没有引入@heyrevia组件库，优先使用@components下面的组件
* 样式布局优先使用在global.css中定义的theme token
* 组件设计原则：UI和逻辑分离，组件合理粒度化
* 单个文件不要超过500行
* import path：优先@/
* 代码编写必须符合lint和pre-commit规范
* 布局时，遵从html标签语义化的原则
* 开发/修改对应功能，遵从现有项目结构分层
